# 🚀 Front-End Practice Guide

This tutorial will teach you different projects based on difficulty levels.

---

## 🟢 Easy Level

- Profile Page (bio, image, links)
- Simple Landing Page
- Contact Form
- Product Page (shop-style)
- Clean Navbar + Footer
- Image Gallery

---

## 🟡 Medium Level

- To-Do List (add / delete tasks)
- Simple Calculator
- Responsive Menu (burger menu)
- Light / Dark Mode 🌙
- Slider / Carousel
- Form Validation

---

## ⚠️ Important

No comments are included in the code.

You will need to figure things out on your own to add more challenge 😈
